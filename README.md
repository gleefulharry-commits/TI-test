# 人格测试网站生成器框架

这是一个**零代码基础可用的独立 HTML 人格测试网站框架**。你只需要修改文件里的中文占位符内容，就能生成属于自己的 MBTI 风格人格测试网站。

## 你能做出什么？

- 12~20 道趣味人格测试题
- 8~16 个基础人格结果 + 3~5 个隐藏人格彩蛋
- 支持自动计分、匹配、稀有度展示
- 单文件 HTML，无需服务器，双击即可打开
- 可一键部署到 Vercel / GitHub Pages / Netlify

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | **唯一需要修改的文件**，包含页面样式、题目、人格库和算法 |

## 快速开始（3 步）

### 第 1 步：下载本仓库

点击仓库首页的 **"Code" → "Download ZIP"**，解压到本地。

### 第 2 步：修改 `index.html`

用任意文本编辑器（甚至记事本）打开 `index.html`，找到下面 5 个【自定义区域】，把中文占位符替换成你自己的内容：

#### 【自定义区域 1/5】题目库
- 位置：`const questions = [...]`
- 做什么：写 12~20 道题，每题 4~5 个选项
- 每个选项需要分配 `scores`，例如 `{ 外向: 3, 社交: 2 }`

#### 【自定义区域 2/5】基础人格库
- 位置：`const personalities = [...]`
- 做什么：写 8~16 个人格结果
- 每个人格需要写 `dimensions`（维度关键词），这是算法匹配的核心

#### 【自定义区域 3/5】隐藏人格库
- 位置：`const hiddenPersonalities = [...]`
- 做什么：写 3~5 个稀有/传说级隐藏人格
- 设置触发 `condition`，例如 "第3题选A且第5题选C"

#### 【自定义区域 4/5】癫题加成（可选）
- 位置：`calculatePersonality` 函数内
- 做什么：让某些奇葩选项额外加分，增加趣味性

#### 【自定义区域 5/5】强制规则（可选）
- 位置：`calculatePersonality` 函数末尾
- 做什么：当某维度爆表时，强制锁定特定人格

### 第 3 步：本地预览

直接用浏览器双击打开 `index.html`，测试所有题目和结果是否正常。

## 部署上线

测试完成后，把整个文件夹推送到 GitHub，然后用 Vercel / Netlify 一键导入部署即可。

## 设计小贴士

- **题目类型搭配建议**：
  - 3~4 道社交偏好类（测内外向）
  - 3~4 道生活习惯类（测秩序/随性）
  - 2~3 道情绪反应类（测稳定/敏感）
  - 2~3 道价值选择类（测理想/现实）
  - 1~2 道彩蛋癫题（制造 viral 传播点）

- **人格命名技巧**：
  - 要有网感、带标签感，例如："工位无期徒刑犯"、"DDL极限运动员"
  - 名字本身就要让人想发朋友圈

- **隐藏人格设计**：
  - 条件是几道特定题目的特定选项组合
  - 不要设计得太容易触发，保持稀缺感

## 算法原理（一句话）

用户答题后，系统累加各维度得分 → 计算每个人格的 `dimensions` 维度总分 → 取最高分的人格作为结果。如果先触发了隐藏人格条件，则直接显示隐藏人格。
